# H1emu Launcher Releases

Public release artifacts and Tauri updater feed for the H1emu Launcher.

Download the latest version from [Releases](https://github.com/H1emu/launcher-releases/releases/latest):

- **Windows:** `H1emu.Launcher_<version>_x64-setup.exe`
- **Linux (any distro):** `H1emu.Launcher_<version>_amd64.AppImage`
- **Linux (Debian/Ubuntu):** `H1emu.Launcher_<version>_amd64.deb`

The launcher updates itself from `latest.json` in the latest release.
